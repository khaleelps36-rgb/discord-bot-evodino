# EvoDino Manager - Discord Bot

بوت ديسكورد لإدارة السيرفر مبرمج باستخدام Node.js ومكتبة Discord.js (v14).

## المجلد الحالي
`C:\Users\KHALEEL\.gemini\antigravity\scratch\discord-bot`

## الأوامر المتاحة (Slash Commands)
- `/ping` - فحص سرعة استجابة واتصال البوت.
- `/help` - عرض قائمة الأوامر والمساعدة.
- `/serverinfo` - إحصائيات ومعلومات تفصيلية عن السيرفر.
- `/userinfo` - فحص معلومات وتاريخ حساب أي عضو.
- `/clear` - مسح عدد محدد من الرسائل في الروم (يتطلب صلاحية إدارة الرسائل).
- `/kick` - طرد عضو مخالف من السيرفر (يتطلب صلاحية طرد الأعضاء).

## طريقة التشغيل اليدوي
```bash
npm start
```
